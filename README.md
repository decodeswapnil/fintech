# FinanceHub

A full-stack financial web application that allows users to track real-time stock market data, manage portfolios, and build personalized watchlists.

Live Demo: https://finzo.pages.dev/

## 🔗 Features

- 🔐 Secure user authentication using Firebase Authentication  
- 📈 Real-time stock data integration via Financial Modeling Prep (FMP) API  
- 📊 Portfolio and watchlist management with Firebase Firestore  
- 📌 Responsive UI built with modern JavaScript and CSS

## 🧠 Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | HTML, CSS, JavaScript |
| Backend / Services | Firebase Authentication & Firestore |
| API | Financial Modeling Prep (FMP) API |
| Hosting | GitHub Pages |
